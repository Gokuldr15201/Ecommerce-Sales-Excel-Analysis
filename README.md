# E-Commerce Sales Analysis using Excel

## 📊 Project Overview

This project analyzes e-commerce sales data using Microsoft Excel to identify sales trends, product performance, customer behavior, payment patterns, and profitability.

The project demonstrates practical Excel data analysis skills including data cleaning, formulas, PivotTables, charts, KPI analysis, and dashboard creation.

## 🛠️ Tools & Technologies

* Microsoft Excel
* PivotTables
* Excel Formulas
* Charts
* Data Analysis
* Dashboard Design

## 📁 Dataset

The dataset contains e-commerce transaction data with information such as:

* Order ID
* Order Date
* Customer
* Product
* Category
* Region
* State
* Sales
* Quantity
* Discount
* Profit
* Payment Mode

## 🔍 Analysis Performed

### Sales Analysis

* Total Sales

* Category-wise Sales
* State-wise Sales

### Time Analysis

* Monthly Sales Trend
* Sales performance over time

### Customer & Order Analysis

### Profitability Analysis

* Discount vs Profit

## 📌 Dashboard

The final Excel dashboard provides an interactive overview of the business performance using KPI cards, charts, and slicers.

### Key Dashboard Metrics

* Total Sales
* Total Profit
* Total Orders
* Average Order Value

### Dashboard Visualizations

* Category-wise Sales — Clustered Column Chart
* State-wise Sales — Clustered Bar Chart
* Monthly Sales Trend — Line Chart
* Sales by Payment Mode — Doughnut Chart
* Product-wise Sales — Treemap
* Discount vs Profit — Scatter Chart

## 💡 Key Business Insights

The analysis helps identify:

* Best-performing product categories
* High-performing states
* Monthly sales trends
* Popular payment methods
* Top-performing products
* Relationship between discounts and profit
* Areas where business performance can be improved
